운영자와 문의

이 앱은 Wilgon Lab이 개발했습니다. 개인정보 관련 문의는 tonydev901@gmail.com으로 보내 주세요.

기기에 저장되는 정보

사용자가 직접 입력한 거래 기록(날짜, 통화, 수량, 원화 금액, 통장 이름, 메모), 목표 환율, 매도 비용 설정은 기기 안의 앱 저장소(localStorage)에 보관됩니다. 개발자는 이 기록을 별도 서버로 전송하거나 수집하지 않습니다. 계정 로그인, 은행 로그인 정보, 계좌 비밀번호를 요구하지 않습니다.

환율 정보 요청

환율을 불러올 때 Frankfurter API(ECB 기준 일별 환율)에 기준 통화, 대상 통화, 날짜 범위를 요청합니다. 이 과정에서 IP 주소, 요청 시각, 일반적인 네트워크 요청 정보 같은 통상적인 메타데이터가 해당 API 제공자에 의해 처리될 수 있습니다. 개발자는 이 요청을 사용자 기록과 연결해 별도로 저장하지 않습니다.

광고·푸시·분석

Android 앱에서는 광고, 푸시 알림, 로그인, 행동 분석·추적 기능을 사용하지 않습니다. Android 앱의 사용 행동을 분석 서비스로 보내지 않습니다.

Toss(앱인토스) 버전은 토스 플랫폼 정책에 따라 서비스 개선을 위해 토스 Analytics로 환율 조회와 새 기록 저장 성공 이벤트를 집계합니다. 금액·계좌명·메모·거래 내용은 보내지 않습니다. 이 처리는 Toss 버전에만 해당하며 Android 앱에는 적용되지 않습니다.

백업과 CSV 파일

JSON 백업과 CSV는 사용자가 선택한 위치에 저장됩니다. 파일에는 거래 기록과 설정이 포함될 수 있으므로 공유하거나 다른 사람에게 보낼 때 민감한 정보로 취급해 주세요. 앱은 백업 파일을 자동으로 업로드하지 않습니다.

보관과 삭제

기록은 사용자가 설정에서 ‘모든 데이터 초기화’를 실행하거나 앱을 삭제할 때까지 기기에 남습니다. 앱은 Android 자동 클라우드 백업과 기기 이전을 사용하지 않도록 설정되어 있지만, 운영체제나 기기 제조사의 백업·복원 설정에 따라 데이터가 남을 수 있습니다. 백업 파일은 사용자가 저장한 위치에서 직접 삭제해야 합니다.

환율·손익 정보의 한계

환율과 계산 결과는 참고용 정보이며 실제 은행 적용 환율과 다를 수 있습니다. 미래 환율이나 수익을 보장하지 않고, 투자 자문이나 금융상품 판매를 제공하지 않습니다.
